Checked 2026-10-10. Official sources only (gib.gov.tr, mevzuat.gov.tr, resmigazete.gov.tr, ebelge.gib.gov.tr where GİB publishes its guides). Secondary sources were used only to find the official text.

Note on deep links: neither mevzuat.gov.tr nor gib.gov.tr has per-article URLs or anchors. gib.gov.tr's "Madde Seçiniz" picker scrolls without changing the URL, and the mevzuat.gov.tr text has no madde ids. The most specific stable URL is the law or tebliğ page, so the label carries the article ("VUK md. 231/5").

## For Mert (decided 2026-10-10)

1. Rule 2 wording ("gerekçeyi nota yaz") and whether a 0% Satış line should point to İstisna only. Decided: points to İstisna or another rate; 351 is not possible on the portal.
2. Rule 7b: the "Fatura günü" rate option has no basis in the tebliğ. Decided 2026-10-10: removed.
3. Rule 9b: 22222222222 accepted as a TCKN placeholder. Decided: keep.
4. Rules 11a and 11b: blocking irsaliye date errors without an explicit official rule. Decided: warnings, never blocking.
5. Rule 13: GTİP hint says "Yalnızca". Decided: "Mal ihracatında gerekir".
